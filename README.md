# T-Snake
Terminal based snake game

Made this game for fun. Enjoy it as it is.

## Installation

1. Clone the repo:
```bash
git clone https://github.com/zE0nyx/T-Snake.git
cd T-Snake
```

2. Create a virtual environment:

Windows:
```bash
py -m venv .venv
```

Linux:
```bash
python3 -m venv .venv
```

3. Install Dependencies:
```bash
pip install -r requirements.txt
```

4. Then just run it.
