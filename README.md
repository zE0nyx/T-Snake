# T-Snake
Terminal based snake game

Made this game for fun. Enjoy it as it is.

## Installation

Clone the repo:
```bash
git clone https://github.com/zE0nyx/T-Snake.git
cd T-Snake
```

Create a virtual environment:

Windows:
```bash
py -m venv .venv
```

Linux:
```bash
python3 -m venv .venv
```

Install Dependencies:
```bash
pip install -r requirements.txt
```

Then just run it.
